# Ảnh bìa riêng

Đặt ảnh bìa vào thư mục này rồi khai báo trong `config.js`, ví dụ:

```js
{ title: "Tố Tâm", ..., cover: "covers/to-tam.jpg" }
```

- Tỉ lệ khuyên dùng **2:3** (ví dụ 600 × 900 px), định dạng `.jpg` hoặc `.webp`, dưới 200 KB.
- Chỉ dùng ảnh bạn có quyền: tự thiết kế (Canva…), đặt hoạ sĩ vẽ, ảnh stock miễn phí cho mục đích thương mại (Unsplash, Pexels, Pixabay), hoặc ảnh bìa bản in gốc đã hết bản quyền trên Wikimedia Commons.
- Không lấy bìa từ các trang đọc truyện, nhà sách hay nhà xuất bản khác.
